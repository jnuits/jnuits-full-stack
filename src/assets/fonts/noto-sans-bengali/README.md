# Noto Sans Bengali (Variable Font)

## Attribution & Source
- **Font Family:** Noto Sans Bengali
- **Designers / Authors:** The Noto Project Authors (https://github.com/notofonts/bengali)
- **Upstream Repository:** https://github.com/google/fonts/tree/main/ofl/notosansbengali
- **Version:** Variable font (`NotoSansBengali[wdth,wght].ttf`)
- **License:** SIL Open Font License, Version 1.1 (see `OFL.txt` in this directory)

## Glyph & Script Coverage
- Full Bengali script block: U+0980–U+09FF (consonants, vowels, matras, conjuncts, Bengali digits)
- Full Basic Latin and Latin-1 supplement: U+0020–U+00FF
- Weights supported: Variable `100` to `900` (`wght` axis), including standard JnUITS typography weights 400, 500, 600, 700, and 800.
