# Admin activity collection

The ordinary daily production job `/api/cron/admin-accountability` collects at most 500 native source events per invocation. Schedule `0 3 * * *` means 09:00 Asia/Dhaka, with hour-level timing on Vercel Hobby. This is one application job, not a Codex automation. This release sends no recommendation or peer-notice email.

Set a private, cryptographically random `CRON_SECRET` in Vercel Production before the collection release. Vercel supplies its bearer credential to scheduled calls. The route refuses non-production execution, missing configuration and incorrect authorization; responses are private/no-store. A DB lease prevents concurrent collectors, and expired leases recover after 30 seconds. The work budget is 20 seconds, with a separate two-second lease-release request. A timed-out request never retries business actions. The next daily/operator call resumes missing durable source IDs, including late source rows.

For an operator run, supply `APP_BASE_URL=https://jnuits.org.bd` and `CRON_SECRET` privately in the terminal environment. `node scripts/run-admin-accountability.mjs` previews source collection without adding event receipts. `node scripts/run-admin-accountability.mjs --apply` explicitly imports the bounded batch. Neither command sends mail, changes roles, deletes logs or enables retention. No other origin is accepted, redirects are refused, and printed output contains safe counters only. Never put job credentials into command arguments or committed files.

`partial` means verified individual source receipts exist but uninterrupted coverage has not been established. `unavailable` means no trustworthy native receipt is available; `delayed` means the last collection is older than 48 hours. Missing events never prove inactivity or non-enrollment. A native login row is not proof of admin-workspace entry; current verified workspace boundaries produce their own receipts. Device labels are coarse client-reported values. Network values show the provider/Vercel-observed address only; visitor country remains unavailable.

Audit views/exports require current `admin.audit.read`. Explicit full network details additionally require `admin.security.read`. Cross-account summaries preserve admin-account management visibility as well as audit permission; own compact summaries remain self-service. Exports omit network context and neutralize spreadsheet formulas.
